## What This File Will Contain After Setup

After running `/generate-review-prompts`, this file will contain a comprehensive, workspace-tailored feature-complete workflow prompt with the following sections:

### Overview
A role assignment and objective statement customized to your project's project management style, versioning strategy, and deployment workflow.

### 1. Identify the Completed Feature
Instructions to parse `task.md`, `implementation_plan.md`, and recent conversation history to identify what was built.

### 2. Update Project Management Artifacts
Exact file paths and update instructions for task tracking files (e.g., `task.md`, `implementation_plan.md`).

### 3. Update Project Documentation
Exact paths to backlog, roadmap, and feature-status files with instructions on how to move items to "Completed".

### 4. Update Project Rules & Skills
Instructions to update `GEMINI.md` or create new skills when new architectural patterns, dependencies, or reusable capabilities are introduced.

### 5. Update Knowledge Base & Other Docs
Scan for outdated documentation and update accordingly.

### 6. Update Database Schema/ER Diagram (Conditional)
Project-specific instructions for updating Mermaid ER diagrams or migration logs, with MCP SQL verification commands.

### 7. Create User Guide
Directory paths and formatting guidelines for new user-facing feature documentation.

### 8. Update CHANGELOG & Versioning
Exact `git log`/`git diff` commands, versioning rules (PATCH/MINOR/MAJOR), and workspace-specific version sync instructions.

### 9. Final Verification
Project-specific terminal commands for type-checking, testing, and build verification.

### 10. Commit, Tag & Push (USER ACTION)
Explicit Git commands for the user, with a prominent reminder that these are USER-ONLY operations.
