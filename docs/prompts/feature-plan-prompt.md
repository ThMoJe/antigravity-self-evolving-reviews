## What This File Will Contain After Setup

After running `/generate-review-prompts`, this file will contain a comprehensive, workspace-tailored feature planning prompt with the following sections:

### Workspace Context (Pre-Loaded)
All architectural context pre-filled for your workspace: project description, tech stack with exact versions, database and ORM details, auth provider, deployment pipeline, and active skills — so the planning agent doesn't re-discover the stack on every invocation.

### Pre-Flight Reconnaissance
Exact MCP tool calls and file paths to read before writing the plan, grounded in your actual workspace structure.

### Implementation Plan Structure
Required sections tailored to your domain groups (e.g., Database → Backend → Admin UI → Client → Mobile).

### Coding Standards
Your project's non-negotiable Vibe Coding rules, file size zones, and module conventions, sourced directly from your `GEMINI.md`.

### Handoff Instructions
Instructions to queue the completed plan for `/run-implementation-plan-review-1` and `/run-implementation-plan-review-2`.
