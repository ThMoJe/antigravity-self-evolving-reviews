## What This File Will Contain After Setup

After running `/generate-review-prompts`, this file will contain a comprehensive, workspace-tailored code review prompt with the following sections:

### Overview
A role assignment and objective statement customized to your project's tech stack and architecture.

### Phase 1: Pre-Review Context Gathering
Instructions to collect live data before the review begins (git status, open PRs, recent commits).

### Phase 2: Codebase Analysis
Detailed analysis dimensions including:
- **Correctness** — Logic bugs, edge cases, error handling
- **Security** — Auth guards, input validation, secret exposure
- **Architecture** — Module separation, dependency violations, God Components
- **Performance** — N+1 queries, blocking operations, bundle size
- **AI Context Readiness** — JSDoc coverage, file sizes, naming clarity
- **Dead Code** — Unused imports, orphaned files, stale dependencies

### Phase 3: Vibe Coding Compliance Check
- God Component detection (files > 500 lines)
- `as any` type assertion audit
- Module separation verification (services vs. routes vs. components)

### Phase 4: Report Generation
Output format instructions, grading matrix (Security / Stability / Maintainability / Overall Vibe Score), and the Recommended Actions table with Execution Environment annotations.
