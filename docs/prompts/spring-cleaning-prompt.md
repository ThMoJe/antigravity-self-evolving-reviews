## What This File Will Contain After Setup

After running `/generate-review-prompts`, this file will contain a comprehensive, workspace-tailored spring cleaning prompt with the following sections:

### Overview
A role assignment and objective statement customized to your project's specific dead-code patterns and dependency structure.

### Phase 1: Dead Code Detection
Instructions to identify:
- Unused imports across all workspaces
- Orphaned files with no import references
- Stale utility functions and helper files
- Commented-out code blocks

### Phase 2: Dependency Audit
- Unused `package.json` dependencies (using Knip or manual analysis)
- Outdated packages with security implications
- Duplicate dependencies across workspaces

### Phase 3: Staleness Analysis
- Files with no Git activity in the past 6 months
- Documentation that references deleted files or deprecated APIs
- Config files pointing to non-existent paths

### Phase 4: Report Generation
Output format with severity tiers (High / Medium / Low), estimated cleanup effort, and prioritized action list.
