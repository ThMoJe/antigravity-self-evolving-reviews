## What This File Will Contain After Setup

After running `/generate-review-prompts`, this file will contain a comprehensive, workspace-tailored README generation prompt with the following sections:

### Overview
A role assignment and objective statement customized to your project's specific stack, features, and developer audience.

### Analysis Instructions
Directions to scan the following workspace artifacts before generating the README:
- `package.json` (project name, description, version, scripts, dependencies)
- Directory structure (identify monorepo workspaces: client, server, admin-ui, packages)
- Environment variable files (identify required `.env` variables)
- Mobile presence (Capacitor `android/` directory, native plugins)
- Available global skills and MCP servers

### Required README Sections
A template structure ensuring the generated README includes:
1. **Header** — Project name, badges (version, license), and a one-sentence description
2. **About** — Problem statement and key value propositions
3. **Tech Stack** — Full technology table (frontend, backend, database, infrastructure)
4. **Getting Started** — Prerequisites, installation steps, development server
5. **Features** — Key feature list with brief descriptions
6. **Developer Context** — Active MCP servers, global skills, and the Antigravity 2.0 Execution Environments Matrix
7. **Mobile App** (conditional) — Architecture, build instructions, CI/CD references
8. **Contributing & License**
