## What This File Will Contain After Setup

After running `/generate-review-prompts`, this file will contain a comprehensive, workspace-tailored architecture review prompt with the following sections:

### Overview
A role assignment and objective statement customized to your system's specific architectural layers, dependencies, and infrastructure.

### Phase 1: Live Data Gathering
Instructions to execute MCP queries before analysis begins:
- Database schema and table counts (`mcp_postgres_query`)
- Queue depths and pending jobs (`mcp_redis_list`)
- Recent commit velocity (`git log`)
- Open GitHub issues and PRs (GitHub MCP)

### Phase 2: Architectural Analysis Dimensions
Detailed review across all architectural layers, including:
- **4.1 Database Architecture** — Schema design, index efficiency, migration hygiene
- **4.2 API Layer** — REST/GraphQL structure, middleware chain, auth guards
- **4.3 Service Layer** — Business logic separation, queue usage, background jobs
- **4.4 Frontend Architecture** — Component hierarchy, state management, bundle strategy
- **4.5 Security Posture** — Secret management, CORS, rate limiting, input validation
- **4.6 Mobile Architecture** (if applicable) — Capacitor bridge, native plugins, offline strategy
- **4.7 DevOps & Deployment** — CI/CD pipeline, environment parity, rollback strategy
- **4.8 Dependency Health** — Audit report, license compliance, update backlog
- **4.9 Observability** — Logging, error tracking, performance monitoring

### Phase 3: Architecture Vibe Rating
A scored assessment (1–10) with the **Critical 3**: the three most urgent architectural issues.
